# Configuration templates

All endpoints use non-routable `.invalid` placeholders. No example is a
ready-to-connect profile.

- `hysteria-client.json.example`: replace the VPS endpoint, credential and
  TLS server name; import through the panel.
- `foxhole.conf.example`: UCI options for the `foxhole.panel` section.
  Merge intentionally; do not overwrite an existing router configuration.
- `inbound.json.example`: optional `/etc/foxhole/inbound.json`.
  Provision a valid certificate and private key locally at the named
  paths, set the reachable router endpoint and matching TLS server name,
  and keep file permissions restricted. Do not enable the service until
  provisioning is complete. Accounts are generated by the panel, not by
  copying credentials into this template.

Shared UDP/443 supports individual credentials but one common LAN ACL.
Per-client LAN toggles require `listenerMode: "per-client"` and separate
UDP ports. Do not confuse router inbound users with remote VPS accounts.

Keep completed configurations, QR exports, keys and backups outside Git.
